    从导入到合奏

    1. 先体验原创演示，熟悉播放、A/B 循环和音符编辑。
    2. 干净的单音吉他录音可使用基础模式。整首乐队录音请安装完整引擎，选择完整乐队模式。
    3. 优先上传无损音频。先转写 30–60 秒，确认调弦、BPM 与第一小节重拍，再处理整曲。
    4. 橙色音符或“?”需要复核；点击音符可改音高、时间和指法。修改后保存，或导出到制谱软件继续整理。

    快捷键：空格 播放 / 暂停；← → 前后 3 秒。输入框和弹窗内不触发。

    完整模式使用 Demucs 六轨分离与 Basic Pitch 多音转写。吉他叠录、失真、鼓组分类及演奏技法仍需人工校正。工具不会承诺逐音准确；演示曲不是模型识别结果。
