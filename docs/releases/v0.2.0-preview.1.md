# BandTab Studio v0.2.0-preview.1 · Linux 桌面预览版

本版本提供原生桌面排练工具：导入本地音乐，生成可编辑的乐队谱草稿，听辨校正后跟谱排练。音频在本机处理，不需要账号或 API key。

**本次仅提供 Linux x86_64 程序包。Windows 和 macOS 的源码与构建配置已准备，尚未提供经过验证的安装包。**

## 下载哪个文件

| 附件 | 用途 |
| --- | --- |
| `BandTabStudio-Linux-x86_64-glibc2.43.tar.gz` | 完整软件，约 489 MiB，包含运行库、音频解码器与识别模型，无需安装 Python |
| `SHA256SUMS.json` | 上述程序包的 SHA-256 校验值 |
| `原创练习曲.bandtab` | 在软件中打开的示例歌曲项目，包含音频和预先编写的谱子 |

GitHub 自动生成的 `Source code` 附件是源码，不是安装包。

## 系统与启动

- 构建并验证环境：Ubuntu 26.04、x86_64、glibc 2.43。
- 需要兼容的系统图形/音频库及可用的音频输出设备；不保证较旧 Linux 发行版可运行。
- 完整解压软件包后，打开 `BandTabStudio` 文件夹，运行 `BandTabStudio` 或同目录 `启动BandTab.sh`。
- 请保留同目录所有文件。解压后约 1.4 GiB，曲库、模型缓存与计算缓存还需额外空间。
- 打开「原创练习曲」，或通过「打开分享项目…」导入附件中的 `.bandtab` 示例。

## 主要功能

- 完整乐队六轨分离、单乐器多音转写和基础单音模式。
- 动态跟谱、分轨试听、静音/独奏、慢放和 A/B 循环。
- 吉他/贝斯弦品、音符编辑、待复核标记、保存与撤销。
- 导出 MIDI、MusicXML、文本 TAB。
- 分享包含谱子与音频的 `.bandtab` 项目，在另一台安装了 BandTab 的电脑上继续排练。

## 已验证与已知限制

Linux 环境 26 项自动测试通过，独立程序完成了项目包导入导出、识别进程和真实 AI 分离转谱检查。界面通过离屏渲染检查，当前测试环境没有实体音频输出设备，因此尚未验证实际扬声器或耳机播放。

自动转谱结果是需要校正的草稿。复杂失真、吉他叠录、推弦、滑音、拍号和重拍可能出错；不能保证分开主音与节奏吉他。鼓谱仅提供底鼓、军鼓、踩镲参考。CPU 处理整曲可能较慢，建议先用短片段判断效果。

示例歌曲的谱子为预先编写，不代表自动识别准确率。当前版本没有真实歌曲标注集上的准确率评测。
