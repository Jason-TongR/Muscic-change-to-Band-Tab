# BandTab Studio v0.2.1-preview.1 · Windows 桌面预览版

适合 Windows 10 1809 及以上、Windows 11 的 x64 电脑。中文原生桌面界面，将音乐转成可编辑的乐队谱草稿，支持分轨试听、吉他/贝斯六线谱、慢放、A/B 循环与项目分享。

## 下载哪个文件

- **推荐安装版：** `BandTabStudio-Windows-x64-Setup.exe`。双击安装，从开始菜单启动。
- **免安装版：** `BandTabStudio-Windows-x64-Portable.zip`。完整解压后运行 `BandTabStudio.exe`，保留 `_internal` 等全部文件。
- **体验项目：** `practice-demo.bandtab`。在软件里点击「打开分享项目…」导入。它不是安装包。

两个软件包均包含 Python 运行库、CPU AI 引擎、音频解码器与模型，用户不需要安装 Python。完整包可在离线模型模式下运行；第一次计算缓存与 CPU 分轨可能较慢，建议先用短音频体验。

示例项目在本 Release 中使用英文文件名 `practice-demo.bandtab`，内容与构建时的「原创练习曲」相同。请使用 `SHA256SUMS-release.json` 校验下载文件；`SHA256SUMS.json` 和构建信息保留原始构建文件名，仅供追溯。

## Windows 版改进

- 简体中文/英文安装向导，按当前用户安装，无需管理员权限。
- 开始菜单快捷方式、可选桌面快捷方式和 `.bandtab` 项目的「打开方式」。
- 支持中文与空格路径，关闭窗口时释放音频文件，识别进程隐藏命令窗口。
- 曲库位于 `%LOCALAPPDATA%\BandTab Studio\`，更新程序与卸载均保留用户曲库；重要项目仍建议另行导出备份。

## 检查与已知限制

本版已在 Windows Server 2022 x64 构建机通过 36 项测试，以及便携启动、原生 Qt 窗口、中文路径、项目导入导出、离线六轨 AI、安装、重复安装和卸载保留曲库检查。[查看成功构建记录](https://github.com/Jason-TongR/Muscic-change-to-Band-Tab/actions/runs/42460814921)。验证结果见附件 `Windows-validation.json`，源码提交和依赖版本见 `build-info-Windows-AMD64.json`。

此预览版**未做代码签名**，Windows 可能提示未知发布者。请核对下载来源与 `SHA256SUMS-release.json`，不要关闭系统安全保护。云端构建机未验证实体扬声器、耳机或全部设备驱动。

识别结果是需要人工校正的谱草稿。失真、叠录、推弦、滑音、鼓点及重拍可能有误；示例曲的谱子是预先编写的，不代表自动识别准确率。暂不提供 Windows 7、32 位 Windows 或原生 ARM64 程序包。

本 Release 只发布 Windows 0.2.1。Linux 0.2.0 旧包及其兼容范围见原版本说明；macOS 成品仍待验证。
